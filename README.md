# تابو نئون (Neon Taboo) — بازی کلمات ممنوعه دیسکورد 🎮🔥

یک بازی چندنفره و هم‌زمان (Real-time Multiplayer) **تابو / کلمات ممنوعه** به زبان فارسی (`RTL`) و انگلیسی (`LTR`)، طراحی‌شده به‌صورت اختصاصی برای اجرا در قالب **Discord Activity** با استفاده از `@discord/embedded-app-sdk` و همچنین قابل اجرا در مرورگر معمولی.

---

## ✨ ویژگی‌های کلیدی (Features)

1. **پشتیبانی کامل از Discord Embedded App SDK**:
   - اجرای خودکار `await discordSdk.ready()`، احراز هویت (`authorize` و `authenticate`) و دریافت آواتار، نام کاربری و شناسه دیسکورد بازیکن.
   - تنظیم `base: './'` در [vite.config.ts](file:///w:/Game_projects/tabo/vite.config.ts) و مسیریابی خودکار WebSocket از طریق `/.proxy/socket.io` برای سازگاری کامل با پروکسی دیسکورد.
   - **حالت جایگزین هوشمند (Local Browser Dev Mode)**: اگر بازی را خارج از دیسکورد (مستقیماً در مرورگر) باز کنید، به‌طور خودکار پروفایل آزمایشی مجزا برای هر تب مرورگر می‌سازد تا بتوانید چندنفره را روی سیستم خود تست کنید.
2. **موتور هم‌زمان سرور-محور (Authoritative Express + Socket.io)**:
   - مدیریت اتاق‌ها، تیم فیروزه و تیم یاقوت، تایمر سرور، چرخش نوبت توصیف‌کننده و امتیازدهی لحظه‌ای.
   - **حدس صوتی و متنی هوشمند**: هم‌تیمی‌ها می‌توانند در ویس دیسکورد کلمه را بگویند یا در کادر چت زنده تایپ کنند؛ سرور با یکسان‌سازی حروف فارسی (`ی`/`ک`، حذف نیم‌فاصله و اعراب) به‌طور خودکار حدس درست را تشخیص داده و امتیاز می‌دهد!
   - **زنگ خطای تعاملی روی کلمات ممنوعه**: بازیکنان تیم رقیب می‌توانند مستقیماً روی کلمه ممنوعه‌ای که توصیف‌کننده به زبان آورده کلیک کنند تا نام همان کلمه ممنوعه در اعلان خطا ثبت شود.
   - **ربات‌های آزمایشی و سوییچر دید نقش‌ها**: امکان افزودن یار آزمایشی (ربات) در لابی و تغییر زاویه دید بین «توصیف‌کننده»، «حدس‌زننده» و «ناظر رقیب» برای تست تک‌نفره.
3. **بانک کارت‌های فارسی بازبینی‌شده و دسته‌بندی‌شده (`374` کارت فارسی + `107` کارت انگلیسی)**:
   - ماژول پارسر در [src/data/cards.ts](file:///w:/Game_projects/tabo/src/data/cards.ts) فایل متنی [public/cards.txt](file:///w:/Game_projects/tabo/public/cards.txt) و [src/data/cards.txt](file:///w:/Game_projects/tabo/src/data/cards.txt) را با فرمت استاندارد زیر می‌خواند:
     ```text
     کلمه اصلی : کلمه ممنوع ۱, کلمه ممنوع ۲, کلمه ممنوع ۳, کلمه ممنوع ۴, کلمه ممنوع ۵، کلمه ممنوع ۶
     ```
   - شامل دسته‌بندی‌های متنوع: **میم‌ها و اصطلاحات نسل زد** (`دلولو`، `کرینج`، `سیمپ`، `گوستینگ`، `ردفلگ`، `پشمام ریخت`، `آورا فارمینگ` و...)، **غذاهای ایرانی**، **فرهنگ و زندگی روزمره**، **ضرب‌المثل‌ها و کنایه‌ها**، **فیلم و سریال و مشاهیر**، **تکنولوژی و بازی‌ها** و **شهرها و طبیعت**.
4. **دو زبانه (فارسی RTL ⇄ انگلیسی LTR)**:
   - دکمه تغییر زبان آنی در نوار بالا که کل جهت صفحه (`dir="rtl"` و `dir="ltr"`)، فونت (`Vazirmatn` و `Plus Jakarta Sans`)، اعداد فارسی/انگلیسی و متن رابط کاربری را تغییر می‌دهد.

## 🚀 راه‌اندازی و اجرا (Quick Start)

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای هم‌زمان فرانت‌اند و سرور Socket.io روی پورت 5173
npm run dev
```

سپس آدرس زیر را در مرورگر (یا چند تب مختلف مرورگر برای تست چندنفره) باز کنید:
👉 **http://localhost:5173**

### اجرا در قالب Discord Activity
1. در [Discord Developer Portal](https://discord.com/developers/applications) یک اپلیکیشن بسازید و مقادیر `VITE_DISCORD_CLIENT_ID` و `DISCORD_CLIENT_SECRET` را در فایل `.env` قرار دهید.
2. پورت `5173` را با استفاده از Cloudflare Tunnel عمومی کنید:
   ```bash
   cloudflared tunnel --url http://localhost:5173
   ```
3. آدرس `https://<your-tunnel>.trycloudflare.com` را در بخش **URL Mappings** (`/` -> `your-tunnel.trycloudflare.com`) در پنل دیسکورد وارد کنید.
