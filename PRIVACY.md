# Privacy Policy — HadesHood Taboo

**Last Updated:** October 2026

## 1. Information We Access
When you launch **HadesHood Taboo** inside Discord, the Activity uses the Discord Embedded App SDK to read your basic public Discord profile:
- Discord User ID
- Display Name / Username
- Avatar URL

This information is used solely to display your player name and avatar inside your active game room.

## 2. How Data Is Stored
- **Ephemeral Game State:** All room states, team assignments, scores, guesses, and custom cards exist temporarily in server memory (`RAM`) only while a game room is active.
- **No Permanent Database Tracking:** We do not permanently store, sell, rent, or share your personal data with any third parties.

## 3. Local Browser Storage
The Activity stores user preferences (such as selected theme mode, language preference, and fallback player nickname) locally in your browser's `localStorage`.

## 4. Contact
If you have any questions about this Privacy Policy, please open an issue on our [GitHub repository](https://github.com/ama99/hadeshood-taboo).
